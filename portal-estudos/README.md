📚 Portal de Estudos (Sistema de Acesso e Questionário)
Interface web desenvolvida para fins acadêmicos, integrando telas de formulário de login/cadastro e questionário de perfil de estudante.

🛠️ Tecnologias Utilizadas
* HTML5: Estruturação das páginas `acesso.html` e `questionario.html`.
* CSS3: Estilização customizada em `estilos.css` com layout responsivo e Flexbox.
* JavaScript: Validação de campos e tratamento de eventos em `interação.js`.

📂 Estrutura desta Pasta
portal-estudos/
├── acesso.html        # Página de login e cadastro
├── questionario.html  # Questionário de perfil
├── estilos.css        # Estilos gerais da interface
└── interação.js       # Script de interatividade
